# Cerebrals

**Un moteur de recherche biomédicale, orienté oncologie.**

Cerebrals agrège plusieurs sources — PubMed, ClinicalTrials.gov, TCGA/GDC, GEO —
et produit des synthèses comparatives sur les pathologies cancéreuses : analyse
d'une pathologie seule ou comparaison entre pathologies.

## Fonctionnalités

- Recherche intelligente : mono-pathologie ou comparaison
- Sources : PubMed, ClinicalTrials.gov, TCGA/GDC, GEO
- Synthèses générées automatiquement

## État

- TypeScript / recherche active
